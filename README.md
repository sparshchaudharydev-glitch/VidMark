#VidMark 
A desktop video bookmark player built with Python and PyQt5.
Drop named bookmarks at any timestamp — they persist between sessions 
and appear as visual markers on the seekbar

- 🎥 Play videos (MP4, AVI, WMV and more)
- 🔖 Add named bookmarks at any timestamp
- 💾 Bookmarks persist between sessions
- 📍 Visual markers on seekbar showing bookmark positions
- 🖱️ Hover over markers to see bookmark label
- ⏩ Click a marker to jump to that timestamp
- 🎨 Theme switcher (Dark Grey, Pure Black, Light)
- ⏱️ Timestamp display

🤔 Why VidMark?
Ever rewatched a long lecture, documentary, or gameplay recording just to find that one moment?
VidMark lets you name and pin bookmarks directly onto the seekbar. One scroll and you're exactly where you left off — across sessions, no scrubbing needed.

## How to Run

### Option 1 — Download the exe(No setup required)
Head to the Releases page and download VidMark.exe. Double-click and you're done.

Works on Windows without Python or any dependencies installed.
### Option 2 — Run from source
1. Clone the repo
2. Install dependencies: `pip install PyQt5`
3. Run: `python main.py`
